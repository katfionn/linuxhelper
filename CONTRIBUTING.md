# Contributing

Thanks for your interest in contributing!

## How to contribute

- For substantial changes, open an issue first to discuss the proposed change.
- Keep pull requests focused and describe what you changed and why.
- Include relevant tests or documentation updates when applicable.
- Do not include unrelated changes in a pull request.
